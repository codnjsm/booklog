# 용어

이 앱에서 쓰는 말의 정의. 화면 문구와 코드 이름을 여기에 맞춘다.
원래 `.forge/CONTEXT.md`에 있던 것을 2026.10.20에 저장소로 옮겼다.

독서 기록 앱. 기록(Book/Quote/Word)은 사적인 개인 데이터고, 공유하기는 그중 일부를 친구에게 보여주는 별개의 행위다.

## Language

**기록**:
책·문장·단어를 담고 모으는 사적인 행위. 자동으로 누구에게도 흘러가지 않는다. `Book`, `Quote`, `Word`가 여기 속한다.

**공유하기**:
기록 중 하나를 사용자가 직접 골라 한마디를 붙여 친구에게 공유하는 행위. 기록과 분리된 별개의 행위이며, 기록을 남긴다고 자동으로 공유되지 않는다.
_Avoid_: 발행, 게시, 포스팅 (동사로는 "공유하다"를 쓴다. 원래 "발행"이었으나 대상이 물건인 동사라 "친구에게 발행"이 어색해서 2026-09-08에 교체했다)

**게시물 (Post)**:
공유 결과로 생기는 한 건의 공유 단위. 공유한 시점의 기록 내용을 스냅샷으로 담고 있어, 원본 기록이 나중에 수정·삭제돼도 게시물은 그대로 남는다.
_Avoid_: 포스트

**첨부**:
게시물이 담고 있는 원본 콘텐츠 — 문장(인용구) 또는 책 한 권. 공유할 때 반드시 하나를 고른다.

**피드**:
친구 탭에서 본인과 친구들의 게시물을 시간순으로 모아 보여주는 화면.
